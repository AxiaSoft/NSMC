# 📋 تغییرات ربات محافظ سوپرگروه (NSMC Security Bot)

## نسخه ۴.۱.۰ — ۲۰۲۶-۱۱-۱۳

### 🐍 پشتیبانی کامل از پایتون ۳.۱۲ / ۳.۱۳ / ۳.۱۴

- **شیم event loop پیش از import پایروگرام:** پایتون ۳.۱۴ دیگر به‌صورت خودکار لوپ نمی‌سازد و
  `asyncio.get_event_loop()` خطای `RuntimeError: There is no current event loop in thread 'MainThread'`
  می‌دهد؛ Pyrogram رسمی 2.0.106 دقیقاً در زمان import همین تابع را صدا می‌زند و ربات پیش از شروع
  کار می‌شکست. تابع `_ensure_event_loop_for_legacy_pyrogram()` پیش از `import pyrogram` اجرا می‌شود
  و در صورت نبود لوپ، یک لوپ استاندارد می‌سازد و ثبت می‌کند (روی پایتون‌های قدیمی بی‌اثر است).
- **لایه سازگاری `disable_web_page_preview`:** در kurigram این پارامتر از `edit_text`/`reply_text`
  حذف شده و جای خود را به `link_preview_options` داده است. پوسته `_install_link_preview_compat()`
  فقط در صورت نیاز فعال می‌شود و پارامتر قدیمی را شفاف به `LinkPreviewOptions(is_disabled=True)`
  تبدیل می‌کند؛ بنابراین هر ۲۲ فراخوانی موجود در ربات بدون تغییر روی همه کتابخانه‌ها کار می‌کنند.
- **ساخت یکدست مجوزها:** توابع `restricted_chat_permissions()` و `unrestricted_chat_permissions()`
  هر دو امضای قدیمی (`can_send_media_messages`) و جدید (`can_send_photos` و …) را امتحان می‌کنند،
  زیرا pyrofork کلیدواژه‌های قدیمی را با `TypeError` رد می‌کند.
- **دسترسی سازگار به پیام فورواردشده:** هلپرهای `is_forwarded_message`، `get_forward_user`،
  `get_forward_user_id`، `get_forward_chat`، `get_forward_sender_name` و `get_forward_date`
  ابتدا از شیء جدید `forward_origin` و در نبود آن از فیلدهای قدیمی می‌خوانند؛ این کار هم
  هشدارهای deprecation فورک‌ها را حذف می‌کند و هم بن/آزادسازی از روی پیام فورواردشده را
  روی همه نسخه‌ها سالم نگه می‌دارد.
- **تشخیص خودکار کتابخانه و محیط اجرا:** `detect_telegram_library()`، `detect_crypto_acceleration()`،
  `detect_mixed_installs()`، `runtime_report()` و `compatibility_warnings()` اضافه شدند. در لحظه
  روشن شدن ربات، گزارش سازگاری به کنسول و **فقط به پیوی اونر** ارسال می‌شود (هرگز گروه).

### 📦 وابستگی‌ها

- `requirements.txt` حالا environment marker دارد و pip خودش انتخاب می‌کند:
  - پایتون < ۳.۱۲ → `Pyrogram==2.0.106` + `TgCrypto==1.2.5`
  - پایتون ≥ ۳.۱۲ → `kurigram>=2.2.27` + `tgcrypto2>=1.3.6` (wheel آماده تا cp314، شامل ویندوز ۳۲/۶۴ بیتی)
- با این ترتیب، دیگر نیازی به کامپایلر MSVC برای نصب `TgCrypto` روی پایتون ۳.۱۴ نیست و
  نصب هم‌زمان دو کتابخانه تلگرام (که ماژول `pyrogram` را خراب می‌کند) رخ نمی‌دهد.
- فایل جدید `Security/INSTALL.md`: راهنمای نصب برای ویندوز ۳.۱۴، ویندوز ۳.۱۱، ترموکس و
  لینوکس/macOS + جدول نصب جداگانه هر کتابخانه + جدول عیب‌یابی خطاهای رایج.

## نسخه ۴.۰.۰ — ۲۰۲۶-۱۱-۱۳

### ۱) 🔒 لاگ آنلاین/آفلاین فقط در پیوی اونر
- تابع جدید `send_status_log()` اضافه شد؛ اعلان **روشن شدن**، **خاموش شدن** و **کرش** ربات
  فقط و فقط به پیوی آیدی‌های ثبت‌شده در `admin_ids` ارسال می‌شود.
- برخلاف سایر لاگ‌ها، این اعلان با خاموش بودن ماژول `logging` هم مسدود نمی‌شود تا اونر
  همیشه از وضعیت ربات باخبر بماند (از منوی «🔔 لاگ و اعلان‌ها» قابل خاموش کردن است).
- قفل سخت‌گیرانه در `send_log`: اگر `log_channel_id` برابر با یکی از گروه‌های محافظت‌شده باشد،
  **هیچ** لاگی به داخل آن گروه ارسال نمی‌شود و هشدار آن فقط به پیوی اونر می‌رود.
- گزینه جدید `notifications.send_logs_to_channel` (پیش‌فرض: خاموش) → سایر لاگ‌های امنیتی
  هم به صورت پیش‌فرض فقط به پیوی می‌روند، مگر اینکه خودتان روشنشان کنید.
- در شروع کار ربات، پیکربندی کانال لاگ بررسی و در صورت خطرناک بودن به اونر هشدار داده می‌شود.

### ۲) 🚫 بن کردن اعضای گروه از پیوی ربات توسط اونر
ماژول جدید «مدیریت اعضا» با چهار مسیر اجرایی:

| مسیر | توضیح |
| --- | --- |
| منو | پنل اصلی ← 🚫 مدیریت اعضا ← انتخاب گروه ← لیست اعضای تأیید نشده ← دکمه «⛔ بن» |
| لیست بن‌شده‌ها | خواندن زنده لیست بن‌شده‌های گروه از تلگرام + دکمه «✅ آزادسازی» برای هر نفر |
| بن دستی | ارسال آیدی عددی، `@username`، لینک `t.me/...` یا `tg://user?id=...` در پیوی (همراه با دلیل اختیاری) |
| فوروارد | فوروارد پیام کاربر به پیوی ربات → باز شدن پنل اقدام برای همان کاربر |

- دستورهای متنی جدید: `/ban <group_id> <user_id|@username> [دلیل]`، `/unban`، `/id`، `/moderation`.
- بررسی‌های امنیتی پیش از اجرا: رد کردن بنِ **مالک گروه**، **ادمین گروه** و **ادمین‌های مجاز ربات**،
  بررسی ادمین بودن ربات و دسترسی `Restrict Members`، جلوگیری از بن تکراری.
- هنگام بن، تایمر کپچای کاربر لغو و از صف `unverified_joins` پاک می‌شود تا بن به Kick تبدیل نگردد.
- سابقه کامل هر بن/آزادسازی (مجری، دلیل، زمان) در `bot_state.json` ذخیره و در لیست بن‌شده‌ها نمایش داده می‌شود.
- عملیات `Sweep` هم اکنون از همان هسته بن استفاده می‌کند و سوابقش ثبت می‌شود.
- گزارش بن/آزادسازی فقط به پیوی اونر می‌رود؛ **گروه هیچ پیامی دریافت نمی‌کند**.

### ۳) 🎨 بازنمایی دوباره منوها
- منوی اصلی: آپ‌تایم زنده، نسخه ربات، تعداد گروه‌ها، صف کپچا، سوابق بن و وضعیت فشرده ماژول‌ها.
- منوی جدید «🔔 لاگ و اعلان‌ها» برای کنترل کامل مقصد لاگ‌ها + دکمه «🧪 تست لاگ (فقط پیوی)».
- منوی جدید «📚 راهنما» با توضیح کامل قابلیت‌ها و دستورهای پیوی.
- صفحه‌بندی (Pagination) برای لیست گروه‌ها، اعضای تأیید نشده، بن‌شده‌ها و گزارش‌ها + دکمه تنظیم اندازه صفحه.
- دکمه «🚫 بن» مستقیم داخل گزارش لینک‌های دعوت و گزارش اد مخاطبین.
- تأییدیه دومرحله‌ای برای همه عملیات مخرب (بن، آزادسازی، Panic، Sweep).
- پینگ واقعی API تلگرام به جای عدد تخمینی، و نمایش نسخه پایتون/پایروگرام/پلتفرم در «ℹ️ وضعیت سیستم».

### ۴) 🐞 رفع باگ‌ها و بهبود پایداری
- رفع `NameError` در مسیر «افزودن ربات توسط کاربر عادی» (متغیر `is_inviter_admin` پیش از تعریف استفاده می‌شد)
  که باعث کرش هندلر و **رد شدن بی‌صدا بات‌های اضافه‌شده** می‌شد.
- کلیدگذاری صف کپچا و اعضای تأیید نشده بر اساس «گروه + کاربر» (`chat_id:user_id`)؛
  پیش‌تر یک کاربر در دو گروه، رکورد گروه دیگر را بازنویسی می‌کرد. `bot_state.json` قدیمی به‌صورت خودکار مهاجرت می‌شود.
- ادغام عمیق (`deep merge`) تنظیمات پیش‌فرض با `config.json` موجود → کلیدهای جدید بدون ویرایش دستی فایل اضافه می‌شوند.
- مدیریت بهتر `FloodWait` در ارسال لاگ، اخراج، بن و آزادسازی.
- پاکسازی خودکار حالت‌های ورودی نیمه‌تمام پیوی و دلیل‌های بن استفاده‌نشده در تسک ساعتی.

## نصب و اجرا

```bash
cd Security
pip install -r requirements.txt      # یا: pip install pyrogram tgcrypto
python bot.py
```

> ⚠️ **نکته امنیتی مهم:** فایل‌های `config.json` (حاوی `bot_token` و `api_hash`) و
> `anti_raid_bot_session.session` در تاریخچه Git این ریپازیتوری ثبت شده‌اند.
> توصیه می‌شود توکن ربات را در @BotFather با دستور `/revoke` بازنشانی کنید و این فایل‌ها را
> از ردیابی Git خارج کنید:
>
> ```bash
> git rm --cached Security/anti_raid_bot_session.session Security/anti_raid_bot_session.session-journal Security/config.save
> ```
